# Card System 

## Overview

## Data Format
- Name 
- Type
- Cost 
- Attack (or 0)
- Block  (or 0)

## Loading Process
1. JSON file is read
2. Enemy objects are extracted and created
3. Enemies are grouped together based on difficulty
